# Дедлайн-доска
[Посмотреть опубликованную версию](https://nikiforovadaria200.github.io/dedline-doska/)

Учебный проект: доска личных задач школьника с тремя колонками статусов. Сегодня готов только каркас, а данные и логика появятся в следующих спринтах.

## Стек
Чистые HTML, CSS и JavaScript. Без фреймворков, сборщиков, npm и TypeScript.

## Что умеет
- Рисует список карточек из массива-заглушки.
- Показывает сообщение, если список пуст.
- Перестраивается в одну колонку на 320 px, в две от 640 px и в три от 1024 px.
- Подсвечивает элементы при навигации клавишей Tab.
- Связывает подписи полей с самими полями через label и id.
